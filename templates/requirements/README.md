# Requirements Conditional Packs

`templates/REQUIREMENTS_TEMPLATE.md` のCore要件に加えて、Projectや変更内容に該当するPackだけ使います。

TemplateはRule本文の正本ではありません。判断基準は各Owner Docを確認します。

- [Visual / UI](VISUAL.md) — User-facing UI、新規Page、Meaningful Visual Change
- [Learning](LEARNING.md) — `LEARNING` Profile
- [Game](GAME.md) — `GAME` Profile
- [Diagnostics](DIAGNOSTICS.md) — Interactive ProjectでRuntime Diagnostics / Remote Handoffが必要な場合

該当しないPackを埋める必要はありません。
