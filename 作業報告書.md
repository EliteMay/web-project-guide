### Rule Hygiene

- 一般Research Methodは`docs/20`を維持
- UI / UX / Accessibility一般原則は`docs/04`を維持
- Visual Researchは`docs/18`を維持
- Structure / Flow固有Research Workflowだけを`docs/22`へ分離
- Project固有IA / Sitemap / Flow / State Matrixは対象Projectへ保存する
- 新しいStable Gateは追加しない
- Sidebar / Top Nav / Tabs等の固定PatternをDefault化しない

### Compatibility

- 既存ProjectのRuntime / Storage / Schema / Deployment変更なし
- 既存ProjectのIA / Navigation / Flowを自動Migrationしない
- Visualだけの修正へStructure Researchを一律要求しない
- Card Sorting / Tree Testing / Tutorial / Autosave等を全Projectへ必須化しない
