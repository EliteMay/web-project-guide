## 2026-09-14 Human Guide P0改善

### 目的

類似するDocumentation / Standards Siteとの比較結果をCurrent `web-project-guide`へ反映し、Rule本文を増やすのではなく、人が必要なRuleへ到達するための**探し方・Routing・Navigation・Regression Guard**を強化した。

### 実装

- `HUMAN_GUIDE_REQUIREMENTS.md`でHuman Guide P0 Contractを正式化
- `site/data/human-guide-manifest.json`をPresentation metadataの正本として追加
- Canonical Human GuideをManifest-driven shared shell / Global Navigationへ統一
- Current page state、Skip Link、Guide release state表示を共通化
- Narrow viewportのGlobal Tabsをhorizontal scrollで到達可能に修正
- `site/pages/search.html`でSite-wide Searchを追加
  - Owner / 正本
  - Current Contract
  - Human Guide / 要約
  - Catalog / 実例
  を区別
- Canonical Human GuideもSearch Registryへ追加し、Human Guide結果は公開Pageへ遷移
- HTMLの`script` / `style` / markupを検索Index用本文から除外
- `site/pages/task-router.html`で`maintenance/rule-router.json`を直接利用するHuman Task Routerを追加
- Rule Finderをshared shellへ移行し、Owner一覧をPublic Search Registryから生成
- Root compatibility URLを維持
- Private `web-project-data`をPublic Searchへ含めないContractを維持

### Regression / Failure Review

Rule Finderのshared shell移行Diffで、既存の次3機能カードが一度欠落した。

- GitHub Pages
- Dependencies / Assets
- Observability

PR diff reviewでMerge前に発見して復元した。原因はPresentation / Navigation検証に比べ、置換前Content Coverageの自動検証が弱かったこと。

再発防止として:

- `tests/validate-rule-finder-coverage.mjs` — 既存19機能群を固定
- `tests/validate-site-search-coverage.mjs` — Canonical Human GuideのSearch Registry Coverageを固定
- `tests/validate-human-guide.mjs` — Manifest / Shell / Compatibility / Public Data boundaryを検証

をCIへ追加・強化した。長期Learningは`PROJECT_LEARNINGS.md`の`PL-F-018`へ保存する。
