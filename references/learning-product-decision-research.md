## Research question

What additional decision depth is justified for a Web learning / explanation product beyond `Starting Knowledge + Content Depth + Understanding Check`?

## Evidence map

### IES / What Works Clearinghouse — Organizing Instruction and Study to Improve Student Learning

Source: https://ies.ed.gov/ncee/wwc/PracticeGuide/1

Relevant evidence-backed recommendations include:

- spacing important learning across time;
- interleaving worked examples with problem solving;
- connecting abstract and concrete representations;
- using quizzes for active retrieval / re-exposure;
- using delayed review;
- asking deep explanatory questions.

Promotion implication:

- A learning product should not equate `lesson viewed` with learning.
- Worked examples, independent practice, retrieval, review, and explanatory questions should be chosen based on the intended learning outcome rather than included mechanically in every lesson.
- If durable retention is an explicit outcome, a review / retrieval path can be part of the product contract.

### IES / What Works Clearinghouse — Using Technology to Support Postsecondary Student Learning

Source: https://ies.ed.gov/ncee/wwc/PracticeGuide/25

Relevant recommendations include varied digital resources, self-regulated learning support, and timely / targeted feedback on learner performance.

Promotion implication:

- Technology is useful when it supports the learning process; feature count is not the objective.
- Feedback should be connected to learner performance and next action, not only a score or completion badge.
- Learning flow may need learner-control / self-regulation support when the product expects independent study.

### Education Endowment Foundation — Feedback

Source checked: https://educationendowmentfoundation.org.uk/16-19/developing-independent-learners/feedback

Relevant current guidance emphasizes feedback relative to goals / outcomes, specific guidance for improvement, and giving learners an opportunity to act on feedback.

Promotion implication:

- Assessment and feedback need alignment with the declared learning objective.
- Feedback is stronger when it tells the learner what to do next and the product provides a path to act on it.

## Decision synthesis

The Common Guide should add decision depth for:

1. observable learning outcomes;
2. prerequisite / concept dependency;
3. diagnostic / placement only when learner variance makes one fixed path misleading;
4. choosing explanation, worked example, comparison, misconception treatment, practice, retrieval, and review by outcome / difficulty;
5. separating completion, recall, understanding, application, and mastery evidence;
6. goal-aligned feedback and next-step behavior;
7. freshness / version applicability for time-sensitive technical learning content;
8. beginner learning path vs quick-reference use.

## Over-application boundaries

Do **not** convert the evidence into universal requirements for:

- spaced-repetition infrastructure;
- quizzes on every lesson;
- fixed mastery percentages;
- adaptive learning engines;
- formal prerequisite graphs for tiny content sets;
- mandatory learner accounts or analytics;
- a specific pedagogy for every subject.

The product should select only the mechanisms that materially support its intended learning outcome, learner level, retention horizon, and content type.
