# DesignShelf Companion Tool Evidence

> Non-normative reference. Current common visual rules are owned by `docs/04-ui-ux-accessibility.md` and `docs/18-domain-first-visual-research.md`.

This reference preserves the project-specific workflow that previously lived inside the common UI owner.

## Context

`EliteMay/DesignShelf` has been used as a companion tool for comparing visual directions. It is **not** a mandatory template source and is not the common visual-rule owner.

Repository:

- https://github.com/EliteMay/DesignShelf

## Useful workflow observed

1. Define Purpose / Workflow / Information Architecture in the target project.
2. Establish a structure-first wireframe before color/effects.
3. Compare 2–3 structurally different directions.
4. Do not copy a direction literally; adapt navigation, density, primary action, and content model to the target project.
5. Choose palette after structure is credible.
6. Add decorative effects only where they have a role.

## Direction attributes used as comparison vocabulary

- Navigation Type
- Main Structure
- Content Density
- Alignment
- Typography Direction
- Visual Emphasis
- Image / Screenshot Usage
- Component family / density
- Spacing Rhythm
- Color Rule
- Decorative Effect Policy
- Signature

These dimensions should not be treated as independent random knobs. A useful candidate is a coherent combination with a reason it fits the target project.

## Failure / caution evidence

- `centered hero + 3 cards` may remain one possible skeleton but should not be chosen merely because an AI generated it first.
- Random suggestions are ideation inputs, not completion evidence.
- Palette changes do not make an unchanged layout a new design direction.
- A fixed catalog of layout IDs is not a list of correct answers.
- A companion tool’s current UI order does not override the guide’s structure-first workflow.

## Transfer boundary

Transfer:

- comparison vocabulary
- direction exploration
- structural candidate comparison

Rebuild:

- target project navigation
- density
- content hierarchy
- visual material
- primary task

Do not copy automatically:

- exact layout ID
- palette
- card count
- effect amount
- spacing values
- current DesignShelf UI structure
