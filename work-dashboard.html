Integration Worker I

Iは準備作業をやり直す役ではなく、各Worker Branchの完成成果物を現在のmainへ安全に適用する役です。

このRunの流れ

並列にするのは準備まで。正式反映は直列にします。

1

A/B/C/Dを別会話で開始

上の開始文をコピーして、それぞれ新しい会話へ貼ります。各Workerは専用Branchをclaimします。

2

各Workerが専用Branchで完成させる

調査、重複確認、判断、完成版ファイル、change-set、事前Validationまでを自分のRunフォルダへ保存します。Data mainへ直接書きません。

3

ready_for_applyへ

「考えてください」ではなく、Iが設計し直さなくても適用できる状態まで仕上げます。

4

IがWorker Branchと現在mainを再照合

古いGuide/Dataを前提にしていないか、他Workerと意味的にぶつからないかを確認します。

5

正式反映 → Validation → PR → Merge

Iがintegration branchへ1つずつ適用し、最終状態で検証してから完了にします。Worker Branch自体はmainへ直接mergeしません。

表示元は公開用の要約データです。Private Data Repositoryの詳細内容そのものをブラウザから直接取得しません。
